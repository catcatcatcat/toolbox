# zine-fold — 八折小誌拼版器

把 8 張頁面圖排進一張 A4 橫向紙上，列印後折三次、剪一刀，就是一本 8 頁小誌（one-sheet zine／八つ折り本）。

**你只要專心排版每一頁，拼版（imposition）交給這個工具。**

## 使用方式

```bash
open index.html
```

單一檔案、零相依、零安裝，雙擊用瀏覽器打開即可，離線可用。
線上版：<https://toolbox.catcatcatcat.cc/zine-fold/>（也可直接把頁面存成 HTML 帶走）。
圖片全部在瀏覽器本機處理，不會上傳到任何伺服器。

## 流程

1. 在 Canva／Figma 排好每一頁，各自匯出成圖片，命名 `1.png` ～ `8.png`
   （建議每頁比例接近 A7 直式 74 × 105 mm）
2. 打開 `index.html`，一次選 8 個檔，或把圖片直接拖進頁面
   （拖到整區從第 1 頁開始填，拖到某一格就從那格開始往後填；兩種方式都依檔名數字排序）
3. 按「列印 / 存成 PDF」
4. 列印設定：A4、**橫向**、縮放 **100%（實際大小）**、關閉頁首頁尾、**單面列印**

## 第一次使用請先驗證版型

八折本的折法有鏡像變體，網路上流傳的版型不一定符合你的折法。

1. 「模式」切到 **測試頁（印編號）**
2. 印一張、折起來
3. 翻頁順序若是 1 → 2 → … → 8 且每頁正立，版型正確
4. 不正確就切到「版型對照表」按預設 B，或逐格手動調整（設定會存進 localStorage）

## 功能

| 功能 | 說明 |
|---|---|
| 批次匯入 | 一次選 8 檔，依檔名數字排序填入 |
| 拖放匯入 | 圖片拖進整區從第 1 頁填；拖到單格從該格往後填；非圖片檔自動略過 |
| 拼版預覽 | 即時顯示 A4 橫向拼版結果 |
| 測試頁模式 | 印出 1–8 編號與方向箭頭，用來驗證版型 |
| 版型對照表 | 8 格各自指定頁碼與 180° 旋轉；兩組預設 + 手動 |
| 填滿方式 | cover（填滿裁切）／contain（完整顯示留白） |
| 內縮留白 | 每頁邊緣留白 mm，避開印表機不可印區 |
| 輔助線 | 折線（灰虛線）與切線（紅實線）；可選是否一起列印 |
| 設定記憶 | 版型與選項存在 localStorage；圖片不儲存 |

## 版面規格

A4 橫向 297 × 210 mm，切成 4 欄 × 2 列，每格 74.25 × 105 mm（約 A7 直式）。
切線位於中央橫折線、由左起 74.25 mm 處延伸 148.5 mm（正中央兩格寬）。

## 折法

1. A4 **橫放**，左右對折 → 再左右對折 → 再上下對折，攤開得到 8 格
2. 上下對折回去，沿中央折線**只剪中間兩格的寬度**
3. 攤開，沿長邊上下對折，讓切口在中間
4. 抓左右兩端往中間推，切口撐開成十字形
5. 把四片繞成一疊壓平

## 線上預覽（只能看，不能印）

Artifact：<https://claude.ai/code/artifact/9c72b3dc-c7bf-41ff-857d-8d923bbf2ae6>

嵌入式頁面沒辦法叫出正確的列印對話框，**實際列印一定要用本機的 `index.html`**。
Artifact 版由 `build-artifact.py` 從 `index.html` 自動產生（剝掉 `<html>`／`<head>`／`<body>` 外殼），
所以原始碼只有一份：

```
python3 build-artifact.py /tmp/zine-fold-artifact.html
```
