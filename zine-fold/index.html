八折小誌拼版器

一張 A4、折三次、剪一刀，就是一本 8 頁小誌。你只管把每一頁排漂亮， 哪一頁該擺在紙上哪個位置、要不要倒過來印，交給這裡。圖片全程留在你的瀏覽器，不會上傳。

你正在預覽模式中檢視。版面與設定都能玩，但列印功能在嵌入畫面裡不會正常運作—— 要真的印出來，請直接開 toolbox.catcatcatcat.cc/zine-fold/，或把那個頁面存成 HTML 檔放在電腦上、用瀏覽器打開。

版型校正

八折本的折法有鏡像變體，網路上的版型不一定合你的手。 先用測試頁印一張、折起來看：翻頁順序是 1→2→…→8 且每頁正立就對了。 不對就換預設 B，或逐格手動改——設定會自動記住。

折

折法備忘

  1. 1A4 橫放，左右對折 → 再左右對折 → 再上下對折，攤開得到 8 格。
  2. 2上下對折回去，沿中央折線只剪中間兩格的寬度，也就是預覽上那條紅線。
  3. 3攤開，沿長邊上下對折，讓切口落在中間。
  4. 4抓著左右兩端往中間推，切口會撐開成十字形。
  5. 5把四片繞成一疊、壓平——8 頁小誌完成。
