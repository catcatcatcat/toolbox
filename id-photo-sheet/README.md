# id-photo-sheet — 證明寫真風相紙產生器

上傳一張照片，在瀏覽器本機裁切並重複排成 2×4 的日本證明寫真機風相紙。

## 使用方式

```bash
open index.html
```

單一 HTML、零 runtime 相依、零安裝；雙擊即可離線使用。照片透過 Canvas 在瀏覽器本機處理，
不會上傳到任何伺服器，也不會寫入 localStorage 或 IndexedDB。

## 功能

- 一張照片同步排入八格
- 在相紙預覽上拖曳位置、以滑桿縮放
- 自訂姓名、用途、尺寸、日期、流水號、收據裝飾與注意事項
- 下載 1493 × 1053 PNG
- 無照片時顯示原創的方格紙／藍底相紙版型
- 明示成品僅為證明寫真風圖片，不可用於正式證件
